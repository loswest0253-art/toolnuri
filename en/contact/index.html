Contact and bug reports

This page explains how to report conversion errors, usability issues and content feedback.

The site does not currently operate an on-site contact form. Issues may be submitted through the public GitHub source repository, if Issues are enabled; a GitHub account may be required.

Details useful in a report

Include the tool name, input value and units, expected result, and browser details. Do not share private financial data, identification numbers, or sensitive documents.

External reporting route

If GitHub Issues is disabled, the site owner must publish another contact option.
