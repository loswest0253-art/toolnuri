Use this tool in practice

When to use it

Understand the difference between decimal MB/GB and binary MiB/GiB on storage labels and operating systems.

Worked example

1 GB = 1,000 MB; 1 GiB = 1,024 MiB, or approximately 1.074 GB.

Important limitation

Mbps is a data rate in megabits per second, not a file size in megabytes. Watch capitalization.
