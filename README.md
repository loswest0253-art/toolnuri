# 툴누리 v20 — AdSense 재심사 대비 품질 개선

## 기존 v19 대비
- 20종 도구 × 한국어/영어: 중복적인 일반 가이드를 실제 수치·사용 맥락·오류 가능성을 담은 도구별 고유 설명으로 교체
- 면적·연비·데이터 등 혼동이 잦은 단위에 수치 예시 추가
- 대출 조건 예시 버튼 및 환율 빠른 금액 버튼 추가 (기존 계산 기능 유지)
- 사이트 소개 / 개인정보처리 안내 / 오류 제보 안내: 각 언어 3쪽, 총 6쪽 추가
- 빈 리다이렉트 2페이지(/area/, /scientific/) 광고 스크립트 및 메타태그 제거
- 사이트맵에 루트 및 정보 페이지 추가
- 한국어·영어 메인과 모든 도구에 정보 페이지 연결 추가

## 배포 전 필수 확인
1. 기존 네이버 소유 확인 HTML 파일을 삭제하지 마세요.
2. 문의 페이지에 적힌 GitHub Issues 경로가 활성화됐는지 확인하고, 필요하면 실제 운영 가능한 문의 이메일/폼으로 변경하세요.
3. 개인정보 안내문은 현재 배포 코드에서 확인 가능한 처리만 설명합니다. Google/Cloudflare 운영 방식과 한국 개인정보보호법상 법적 의무는 운영자가 추가 확인해야 합니다.
4. 시크릿 모드에서 각종 변환, 대출 CSV, PDF 변환, 환율 API, 모바일 레이아웃을 실제로 점검하세요.
5. 이 변경은 승인 보장이 아니며, 애드센스의 개별 심사 결과가 우선합니다.
