툴누리 소개

툴누리는 별도 회원가입 없이 계산·변환 도구를 이용할 수 있도록 구성된 무료 웹사이트입니다.

계산기와 단위 변환기는 브라우저에서 계산을 수행합니다. 환율은 별도의 외부 데이터 제공자 정보를 참고하며, 금융·안전·계약 관련 결과는 전문적인 조언이 아닙니다.

현재 제공하는 기능

면적·길이·온도 등 단위 변환, 공학용 계산기, 대출 상환 비교, 환율 계산, 이미지↔PDF 변환 도구를 제공합니다.

사용자의 선택을 돕는 기준

각 도구의 계산 기준·제약·예시를 공개합니다. 잘못된 결과가 의심되면 입력값·단위·날짜를 확인하고 오류를 제보해 주세요.
