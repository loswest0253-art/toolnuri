환율 안내

외부 제공자의 일별 참고 환율을 사용합니다. 은행 환전·카드 결제 시 실제 적용 환율과 수수료는 다를 수 있습니다.

출처: Frankfurter API

사용 방법

금액과 통화를 선택하면 최근 제공된 환율로 계산합니다. 인터넷 연결이 필요합니다.

도구 활용 가이드

환율 결과를 해석하는 방법

금액과 보내는·받는 통화를 고르면 최근 제공된 기준 환율로 환산합니다. 서로 같은 통화도 선택할 수 있습니다.

활용 예시

예: USD→KRW를 선택하면 1 USD당 KRW 기준 환율과 입력 금액의 환산 결과가 함께 표시됩니다.

확인할 점

환율은 일별로 갱신되는 참고치이며 실시간 매매 호가가 아닙니다. 환전 수수료와 카드사 적용 환율은 별도입니다.
