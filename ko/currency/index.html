환율 안내

외부 제공자의 일별 참고 환율을 사용합니다. 은행 환전·카드 결제 시 실제 적용 환율과 수수료는 다를 수 있습니다.

출처: Frankfurter API

사용 방법

금액과 통화를 선택하면 최근 제공된 환율로 계산합니다. 인터넷 연결이 필요합니다.

사용 상황

이 계산기는 외부 제공자의 최근 기준일 환율로 단순 환산합니다. 금액이 같아도 은행 매매기준율·현찰 살 때 환율·카드 청구 환율은 각각 다를 수 있습니다.

계산 예시

예를 들어 환율이 1USD = 1,300KRW라면 100USD의 단순 환산액은 130,000KRW입니다. 이 숫자는 설명용 가정이며 현재 환율을 뜻하지 않습니다.

자주 하는 실수

실제 환전 금액은 환율 우대, 스프레드, 수수료, 거래 시각에 따라 달라집니다. 결과 화면의 기준일을 확인하세요.
