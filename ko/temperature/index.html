변환 결과

변환 기준

°F = °C × 9/5 + 32 · K = °C + 273.15

절대영도는 −273.15°C = −459.67°F = 0 K입니다.

빠른 사용 안내

숫자와 단위를 선택하면 모든 값이 자동으로 변환됩니다.

도구 활용 가이드

온도 단위의 차이

섭씨·화씨는 눈금 간격과 영점이 다르며, 켈빈은 절대온도 단위입니다. 단순 비례 변환이 아니라 영점 보정이 필요합니다.

활용 예시

예: 25°C = 77°F = 298.15 K입니다.

확인할 점

온도와 온도 차이는 변환 공식이 다릅니다. 예를 들어 1°C의 온도 차이는 1.8°F의 차이입니다.
