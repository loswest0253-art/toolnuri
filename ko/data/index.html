변환 기준

1KB = 1,000B, 1KiB = 1,024B, 1B = 8bit입니다.

변환 결과는 참고용이며 적용 표준에 따라 표시 자릿수가 달라질 수 있습니다.

빠른 사용 안내

숫자와 단위를 선택하면 모든 값이 자동으로 변환됩니다.

도구 활용 가이드

KB와 KiB는 왜 다를까요?

저장 장치의 십진 단위(KB·MB·GB)와 컴퓨터 시스템의 이진 단위(KiB·MiB·GiB)를 구분합니다.

활용 예시

예: 1 MB = 1,000,000 B이고 1 MiB = 1,048,576 B입니다.

확인할 점

파일 표시 크기는 운영체제 표시 방식이나 파일시스템 오버헤드 때문에 다르게 보일 수 있습니다.
