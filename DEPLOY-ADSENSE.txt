툴누리 AdSense 인증 수정 v13

1. 이 폴더 내부의 파일과 폴더를 GitHub toolnuri 저장소 최상위에 업로드합니다. (ZIP 자체 업로드 금지)
2. 루트 index.html을 실제 도구 모음 홈페이지로 변경했습니다. /ko/ 및 /en/ 도구 페이지는 유지됩니다.
3. 모든 HTML 페이지의 head에 AdSense 메타태그와 소유권 확인용 스크립트가 들어 있습니다.
4. /assets/ads.js의 개별 본문 광고 슬롯은 승인 전 미리보기 상태로 유지됩니다. 자동 광고는 사이트 승인 이후 애드센스 관리자에서 설정하세요.
5. 배포가 완료되면 https://toolnuri.kr/ 를 열고 페이지 소스 보기에서 google-adsense-account, ca-pub-9355884221957099 를 확인합니다.
6. 다음에 AdSense > 사이트 > toolnuri.kr 에서 코드 스니펫 방식으로 확인을 재시도합니다.
7. 인증 실패가 계속되면 Google이 접근하는 공개 페이지의 응답/차단 여부를 확인해야 합니다. 코드만으로 승인 보장 불가.

주의: 기존 GitHub의 파일을 교체할 때 필요한 폴더 구조를 그대로 유지하세요. 기존 old root 파일이 남지 않도록 교체하세요.
